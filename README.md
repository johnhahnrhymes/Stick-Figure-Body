# Stick-Figure-Body
STICK FIGURE BODY - HOW TO OPEN THE APP
=======================================

You received a file called "Stick_Figure_Body.txt". It is a complete app in a
single file. It was saved as .txt so it is easy to send. To use it, change the
ending of the file name from .txt to .html, then open it in a web browser.

The new name should be exactly:

    Stick_Figure_Body.html

No internet is needed once the file is on your device.


-------------------------------------------------
IPHONE / IPAD (Apple)
-------------------------------------------------
1. Save the file to your device.
   - From Mail or Messages: tap the file, tap the Share button, then choose
     "Save to Files" and pick a folder (for example "On My iPhone").
2. Open the Files app and find Stick_Figure_Body.txt.
3. Press and hold the file, then tap "Rename".
4. Change ".txt" at the end to ".html" and tap Done.
   - If it asks whether to use .html, tap "Use .html".
   - If you don't see the ".txt" ending, you can still type the full name
     Stick_Figure_Body.html in its place.
5. Tap the file to open it.
   - If it opens as a plain preview and the buttons do not work, press and
     hold the file, choose "Share", and open it in Safari or Chrome if either
     is offered.
   - Tip: use the same browser every time you open the app. Your progress is
     stored in that browser.


-------------------------------------------------
ANDROID
-------------------------------------------------
1. Save the file to your phone.
   - From Gmail or Messages: tap the file and choose Download or Save.
     It usually goes into the "Downloads" folder.
2. Open the Files app (called "Files by Google" or "My Files").
3. Open the Downloads folder and find Stick_Figure_Body.txt.
4. Press and hold the file, tap the three-dot menu (or "More"), then tap
   "Rename".
5. Change ".txt" at the end to ".html" and tap OK.
   - If Android asks whether to change the file type, tap OK or Yes.
6. Tap the renamed file and choose Chrome (or your usual browser) to open it.
   - If nothing happens, open Chrome and type this in the address bar:
     file:///sdcard/Download/Stick_Figure_Body.html
   - Tip: use the same browser every time you open the app. Your progress is
     stored in that browser.


-------------------------------------------------
COMPUTER (Windows / Mac)
-------------------------------------------------
Windows: In File Explorer choose View > Show > File name extensions, rename
the file to end in .html, then double-click it.
Mac: In Finder click the file, press Return, change .txt to .html, choose
"Use .html", then double-click it.


-------------------------------------------------
SAVING YOUR PROGRESS (IMPORTANT)
-------------------------------------------------
The app remembers your progress in your browser automatically, but a browser
can lose it (clearing data, private windows, or opening the file a different
way). To keep your trophies safe inside the app file itself:

1. In the app tap "Glaze Me".
2. Tap "Save my progress into the app file".
3. A new copy named Stick_Figure_Body.html is downloaded. It contains all your
   workouts and trophies.
4. Use that new file from now on. Repeat the steps whenever you want to
   update your saved copy (for example after a few workouts).

Moving to a new phone, or sharing? Send the saved Stick_Figure_Body.html and
your progress goes with it. (Anyone you give it to will see your trophies, so
send the original .txt file to friends if you want them to start fresh.)


-------------------------------------------------
GOOD TO KNOW
-------------------------------------------------
- Between saves, your workout history, trophies, and last day are kept in the
  browser on the device you use.
- If the app opens but looks like plain text or code, the file is still
  named .txt. Check the name and try again.
